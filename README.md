# Immortal Paradox Studios — Official Website

A single-file, cinematic portfolio website for the Immortal Paradox Studios universe
(novel • light novels • YouTube music channel • upcoming film adaptations).
Founder & CEO: **Tanmay Rajput**.

## Files

| File | Purpose |
|---|---|
| `index.html` | **The entire website.** Edit this file — everything (CSS + JS + art) is inside it. |
| `README.md` | This file. |

## Preview locally

Just double-click `index.html`, or run a local server from this folder:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

No build step, no dependencies, no external resources — it works fully offline.

## What to edit in `index.html`

Search the file for `EDIT` (or `═══`) — every placeholder is marked with a comment:

1. **Hero stats** — number of novels / light novel volumes / tracks / film projects.
2. **Founder photo** (`#about`) — replace the SVG avatar with a square photo of Tanmay Rajput.
3. **Novel title & synopsis** (`#novel`) — currently the working title "THE INVADERS".
4. **Cover art text** (`#novel`) — title + author inside the SVG book cover.
5. **YouTube channel URL** — search `youtube.com/@ImmortalParadoxStudios` and replace
   every occurrence with the real channel URL (channel banner, all track cards, footer socials).
6. **Track list** (`#music`) — titles, subtitles, durations (6 demo tracks).
7. **Light novel volumes** (`#lightnovels`) — titles, statuses, descriptions (4 volumes).
8. **Film slate** (`#films`) — titles, formats, statuses (3 projects).
9. **Contact email & social links** (`#contact`) — email, X/Twitter, Instagram, Discord URLs.
